A design language for the terminal.

andy's interface grew a screen at a time and it shows: red means "large" in one
column and "dangerous" in the next, cyan means chrome and data and commands and
keys, reverse video means both the cursor and the help panel, and a label
beside a value is written four different ways in four places.

This milestone replaces that with a small set of rules that generate the
interface -- one meaning per channel, one form per idea -- written down where a
reader will find them and enforced by tests, because a design language nobody
can check is a style guide nobody follows.
