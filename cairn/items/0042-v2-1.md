Themes that inherit, and a config file.

A terminal program looks at home when it borrows the window it runs in: the
terminal's own foreground and background, and the sixteen ANSI colours the
user's theme has already chosen. andy does that everywhere except the area map,
which paints fixed xterm-256 greys and so looks foreign in any theme that is
not a dark neutral one.

v2.0 routed every attribute through a named role, which makes a theme nothing
more than a table from role to style. This milestone ships that table, makes the
default one inherit from the terminal completely, and gives andy a config file
for everything that has so far only been a flag.
